# neovim キーバインド チートシート

> VSCodeから移行した人向けに、「何をしたいか」ベースで整理しています。

## このマニュアルの使い方

- **キーを忘れたら `Space` を押す** → [which-key](https://github.com/folke/which-key.nvim) が続きの候補を表示します。各行の説明は設定ファイルの `desc` をそのまま拾っているので、常に最新です。
- `<leader>?` … いま開いているバッファで有効なキーマップ一覧
- `<leader>K` … 全キーマップ一覧
- この Markdown は「よく使うものを俯瞰する」ための静的なまとめです。網羅性より読みやすさ優先。

> 設定を変えたらこのファイルも直す運用です。手順は `.claude/skills/nvim-feature/` を参照。

---

## はじめに：モードの概念（VSCodeにない概念）

nvimにはモードがあります。起動直後は **ノーマルモード** です。

| モード | 入り方 | 何ができる |
|---|---|---|
| ノーマルモード | `Esc` または `jk` | ナビゲーション・コマンド実行（ここが基本） |
| インサートモード | `i` | テキスト入力（VSCodeの通常状態に近い） |
| ビジュアルモード | `v` | テキスト選択 |
| ターミナルモード | `:term` や `Ctrl+\` の中 | `Esc` でノーマル相当（`Ctrl+\` `Ctrl+n`） |

**Leaderキー = `Space`**（以降 `<leader>` と表記）

## ファイルを開く・探す

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| ファイル名で検索して開く | `<leader>sf` | `Ctrl+P` |
| ファイル名で検索（Telescope） | `<leader>ff` | `Ctrl+P` |
| Gitで管理されているファイルを検索 | `<leader>gs` | `Ctrl+P`（.gitignore対応版） |
| ファイルエクスプローラーを開く（親ディレクトリ） | `-` | サイドバーのエクスプローラー |
| ファイルエクスプローラーを開く（Leader版） | `<leader>e` | 同上 |
| 開いているファイル（バッファ）一覧 | `<leader>fb` | `Ctrl+Tab` |
| 関連ファイルに切り替え（実装 ↔ テストなど） | `<leader>oo` | なし |
| 関連ファイルを新しいタブで開く | `<leader>ot` | なし |

### ファイラ（oil.nvim）の中での操作

ファイラはバッファなので、**普通に編集して保存(`:w`)するとファイル操作が実行されます**（作成・リネーム・削除）。

| キー | 動作 |
|---|---|
| `<CR>` | 開く（ディレクトリなら中へ） |
| `-` | 一つ上のディレクトリへ |
| `_` | カレントディレクトリ(cwd)へ |
| `g?` | ヘルプ（キー一覧） |
| `<C-c>` | ファイラを閉じる |
| `.` で始まる項目 | 隠しファイルも常に表示する設定 |

## コードを読む・定義へジャンプ

LSP（Ruby は solargraph）が動いているバッファでのみ有効。`:LspInfo` で起動状況を確認できます。

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| 定義へジャンプ | `gd` | `F12` |
| 宣言へジャンプ | `gD` | `F12`（宣言） |
| 実装へジャンプ | `gi` | `Ctrl+F12` |
| 参照一覧を表示 | `gr` | `Shift+F12` |
| ホバーでドキュメント表示 | `K` | カーソルを乗せる |
| ジャンプ後、元の位置へ戻る | `Ctrl+O` | `Ctrl+-` |
| 戻った後、再び進む | `Ctrl+I` | `Ctrl+Shift+-` |
| シンボル名を一括リネーム | `grn` | `F2` |
| クイックフィックス（コードアクション） | `gra` | `Ctrl+.` |
| 型定義へジャンプ | `grt` | なし |
| ドキュメント内シンボル一覧 | `gO` | `Ctrl+Shift+O` |
| 次の診断（警告・エラー）へ | `]d` | `F8` |
| 前の診断へ | `[d` | `Shift+F8` |
| カーソル下と同じ単語の次の出現へ | `]]` | なし |
| カーソル下と同じ単語の前の出現へ | `[[` | なし |

> `grn` `gra` `grt` `gO` `]d` `[d` は Neovim 標準のキーマップ（設定不要）。

## コードを検索する

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| プロジェクト全体をGrep検索 | `<leader>sg` | `Ctrl+Shift+F` |
| ヘルプを検索 | `<leader>fh` | なし |
| ファイル内を検索 | `/` （下方向）/ `?` （上方向） | `Ctrl+F` |
| 次の検索結果 / 前の検索結果 | `n` / `N` | `Enter` / `Shift+Enter` |
| カーソル下の単語を検索 | `*` （下）/ `#` （上） | なし |
| 検索ハイライトを消す | `Esc Esc` | なし |

### Grep して一括置換（grug-far.nvim）

検索結果がバッファに出るので、**バッファ上でテキストを直接書き換えて反映**できます。

| やりたいこと | キー |
|---|---|
| プロジェクト全体を対象に開く | `<leader>rr` |
| カーソル下の単語で開く | `<leader>rw` |
| 現在のファイルだけを対象に開く | `<leader>rf` |
| 選択範囲の文字列で開く（ビジュアルモード） | `<leader>rr` |

grug-far バッファの中での操作：

| キー | 動作 |
|---|---|
| `<leader>rp` | 置換を実行 |
| `<leader>rs` | バッファの編集内容をファイルへ反映 |
| `<leader>rq` | 結果を quickfix リストへ |
| `<leader>ro` | カーソル位置の該当箇所を開く |
| `<leader>rc` | 閉じる |
| `<leader>rt` | 検索履歴を開く |

## Vim / Neovim の標準キー（設定不要・よく使うもの）

プラグインではなく Vim 本体の機能。詳細は `:help quickref`（vimdoc-ja 導入済みなので日本語）。

### 移動（ノーマルモード）

| キー | 動作 |
|---|---|
| `h` `j` `k` `l` | 左 下 上 右 |
| `w` / `b` | 次の単語の先頭 / 前の単語の先頭 |
| `e` | 単語の末尾 |
| `0` / `^` / `$` | 行頭 / 行の最初の非空白 / 行末 |
| `gg` / `G` | ファイルの先頭 / 末尾 |
| `{` / `}` | 段落単位で上 / 下 |
| `%` | 対応する括弧へ |
| `Ctrl+u` / `Ctrl+d` | 半画面 上 / 下スクロール |
| `f{文字}` / `t{文字}` | 行内でその文字へ / その手前へ |
| `{数字}G` または `:{数字}` | 指定行へ |
| `H` / `M` / `L` | 画面の 上 / 中央 / 下へ |

### 編集（ノーマルモード）

| キー | 動作 |
|---|---|
| `i` / `a` | カーソル前 / 後ろ から挿入 |
| `I` / `A` | 行頭 / 行末 から挿入 |
| `o` / `O` | 下 / 上 に空行を作って挿入 |
| `x` / `dd` | 1文字削除 / 1行削除 |
| `dw` / `d$` / `diw` | 単語削除 / 行末まで削除 / 単語まるごと削除 |
| `cw` / `ciw` / `ci"` | 単語を変更 / 単語まるごと変更 / `"` の中を変更 |
| `yy` / `yw` | 1行ヤンク（コピー）/ 単語ヤンク |
| `p` / `P` | カーソルの後 / 前 に貼り付け |
| `r{文字}` | 1文字置換 |
| `u` / `Ctrl+r` | アンドゥ / リドゥ |
| `.` | 直前の編集を繰り返す |
| `>>` / `<<` | インデント 増 / 減 |
| `J` | 次の行を連結 |
| `gcc` / `gc`（選択中）| 行コメントのトグル（Neovim標準） |

### 検索・置換

| キー / コマンド | 動作 |
|---|---|
| `:%s/old/new/g` | ファイル全体を置換 |
| `:%s/old/new/gc` | 置換（1件ずつ確認） |
| `:s/old/new/g` | 現在行のみ置換 |

### ウィンドウ・バッファ・タブ

| キー / コマンド | 動作 |
|---|---|
| `:sp` / `:vs` | 水平 / 垂直 に分割 |
| `Ctrl+w` `h/j/k/l` | 分割したウィンドウ間を移動 |
| `Ctrl+w` `q` | ウィンドウを閉じる |
| `Ctrl+w` `=` | ウィンドウサイズを均等化 |
| `:bn` / `:bp` | 次 / 前 のバッファ |
| `:bd` | バッファを閉じる |
| `:tabnew` / `gt` / `gT` | 新規タブ / 次タブ / 前タブ |

### ビジュアルモード

| キー | 動作 |
|---|---|
| `v` / `V` / `Ctrl+v` | 文字選択 / 行選択 / 矩形選択 |
| `y` / `d` / `c` | 選択範囲を コピー / 削除 / 変更 |
| `>` / `<` | 選択範囲をインデント 増 / 減 |
| `=` | 選択範囲を自動整形 |
